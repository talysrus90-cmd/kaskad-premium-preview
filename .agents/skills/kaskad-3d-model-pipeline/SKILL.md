# КАСКАД — профессиональная 3D-модель без платных API

В действующем сайте house-3d.source.js уже есть Three.js WebGL-модель дома и материалы, выбираемые посетителем. Не подменяй интерактивную геометрию видео или вращающейся фотографией. Сохраняй текущие 11 заборов, 12 кровель, 5 фасадов, 8+8 цветов, заявки, браузерную историю и мобильное управление.

## Рабочий маршрут

1. Получи права на конкретную архитектурную модель. Проверь лицензии здания, текстур и растительности ДО интеграции в коммерческий сайт. Подходят свои модели, лицензии с разрешённым коммерческим использованием и CC0. Для каждого ассета фиксируй URL, автора и ограничения в assets/3d/ATTRIBUTION.md. Не копируй 3D-сцены других строительных компаний без прав.
2. Основной формат — GLB/glTF, единицы — метры. UV и материалы для групп: facade, roof, trim, glass, fence. При смене фасада обновляй все стены и фронтоны, без расхождений.
3. Цветовые карты PBR — sRGB, normal/roughness/metallic — без цветовой коррекции (linear/noncolor). Проверяй разные ракурсы и время суток при единой экспозиции.
4. Для офлайн-подготовки используй glTF Transform (https://github.com/donmccurdy/glTF-Transform) и gltfpack/meshoptimizer (https://github.com/zeux/meshoptimizer). Meshopt/Draco и KTX2/Basis Universal требуют декодеров в браузере. Оптимизируй реальные GLB, а не заготовку.
5. Мобильный профиль: умеренное количество draw calls, ориентир 1K-текстуры, LOD-деревья; качественный профиль: 2K/повышенный DPR/лучшие тени по требованию. Это не гарантированные пределы, решают замеры на реальном телефоне.
6. RTX 3090 — локальная рабочая станция для рендеринга и подготовки 3D. В браузере Android исполняется WebGL и загружается обычный GLB; ПК-видеокарта не ускоряет телефонный браузер автоматически.
7. NVIDIA Kaolin (https://github.com/NVIDIAGameWorks/kaolin) — отдельная офлайн-подготовка 3D; не прямой браузерный движок. Часть модулей Kaolin в non_commercial. NVIDIA instant-ngp (https://github.com/NVlabs/instant-ngp) имеет некоммерческую лицензию: не встраивай его в коммерческий КАСКАД без разрешения.
8. Перед релизом сравни размеры GLB, FPS, память и время загрузки на Redmi/Samsung, исследуй 4 стороны дома, проверь переключение материалов, форму заявки, Service Worker, GitHub Pages.

## Готовность

Фотореализм считается внедрённым только после конкретной лицензированной детализированной модели GLB, функционирующих переключателей, измерений производительности, визуального теста со всех сторон и живой опубликованной версии. Более качественные картинки или 2K-текстуры сами по себе не дают оснований говорить о готовом фотореализме.
