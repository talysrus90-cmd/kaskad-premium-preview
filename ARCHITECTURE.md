# КАСКАД — PWA и 3D-прототип

Это публичная демонстрационная копия. Основной проект на ПК не изменяется.

## PWA
- `manifest.webmanifest` — иконки и standalone-режим установки на Android/iOS/desktop.
- `service-worker.js` — офлайн-оболочка, сохранённые изображения и защита от повторной загрузки ресурсоёмких файлов. Не кэширует POST или `/api/`.
- `pwa.js` — регистрация после загрузки страницы и установка только после явного действия пользователя. Не вызывает разрешения на уведомления.
- `fonts.css`, `fonts/` — локальные Manrope и Prata, чтобы шрифты не зависели от Google Fonts.
- `assets/ideas/card/` — адаптивные WebP для карточек галереи, полный JPEG остаётся для просмотра с увеличением.

Первое посещение требует интернет. Сохранение страницы офлайн возможно после успешной установки service worker. Не все 300 полноразмерных фотографий скачиваются автоматически.

## 3D
- `3d-house.html`, `3d-house.css`, `house-3d.bundle.js`.
- Three.js 0.187.0 / WebGL. Модель строится из геометрии и текстур в браузере, без тяжелого видеоролика.
- Поворачивается пальцем, двигается камера, регулируются время суток, тени и свет окон.
- Бандл 3D загружается только на отдельной странице. При отсутствии WebGL — обычная фотография.
- Модель демонстрационная, а не готовый проект дома, BIM и не фотосъёмка реального объекта.

## Push
Пока **не подключены**. Для сообщений о заказах/отчётах нужны сервер авторизации, Web Push/VAPID, хранение подписок, явное согласие и управление уведомлениями. Статический GitHub Pages не способен сам отправлять push.

## Навигация
Разделы главной страницы уже работают без полной перезагрузки по якорям. Нет необходимости вводить Next.js/Nuxt и отдельный сервер только для плавного скроллинга. Полноценную SPA/SSR-архитектуру целесообразно оценивать при подключении реальных заявок и кабинета.
