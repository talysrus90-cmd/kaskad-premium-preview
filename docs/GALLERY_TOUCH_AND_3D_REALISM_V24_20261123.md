## 4. Границы результата и дальнейший high-end pipeline
Сцена по-прежнему концептуальная; повышение разрешения и процедурные материалы не превращают её в фотореалистичный построенный дом.
Для действительно высокого уровня нужны индивидуально моделированные окна/отливы/водостоки, PBR кирпич и крыша с нормалями и roughness, реалистичные деревья и кустарники, бассейн с физически корректной водой, фасады/дворы со скульптурной геометрией. Нужно проверять лицензии всех импортируемых ассетов.
Технический путь: Blender на RTX3090 (если установлен и проверен) → GLB/glTF с единицами и material IDs → уровни детализации для телефона/ПК → KTX2/BasisU текстуры → опциональное сжатие геометрии Draco/Meshopt → визуальная QA нескольких ракурсов и реальные Core Web Vitals/FPS мобильных устройств.
Официальные примеры:
