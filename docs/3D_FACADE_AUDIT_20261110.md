# КАСКАД — диагностика фасада, исправление v17 (10 ноября 2026)

## Симптомы и подтверждённые причины

1. Коробка дома была облицована материалом brick с выбранной фактурой фасада, а треугольные фронтоны под скатами крыши были отдельным, не синхронизируемым MeshStandardMaterial с цветом по условию. При переключении на тосканский кирпич, камень и штукатурку фронтоны не получали ту же PBR-текстуру.
2. BoxGeometry с размерами 12.8×6.45×9 м повторял одинаковое количество текстуры на всех четырёх стенах. На торцах шириной 9 м размер кирпича визуально отличался от длинных фасадов 12.8 м.
3. Один контрастный направленный источник солнца ярко освещал лицевой фасад, оставляя заднюю стену сильно затемнённой. Даже одинаковая текстура кирпича казалась другим цветом.

## Что изменено

- Коробка facadeBody и оба фронтона gableFacades теперь используют строго один экземпляр материала brick. Обновление facadeTextures[facade] обновляет одновременно все стены и фронтоны (включая асинхронно загружаемые WebP).
- Фронтоны получили корректные UV-координаты с продолжением вертикального масштаба кирпичной кладки от стен дома.
- UV-настройка первых двух граней BoxGeometry выровнена с отношением физических длин 9/12.8, сохраняя реальные размеры рисунка кладки на торцах.
- Солнце немного смягчено; добавлен дополнительный нейтральный отражённый свет со стороны тыльного фасада. День/вечер/свет в окнах остаются интерактивными.
- Глобальная мобильная навигация, форма заявки, телефон, проекты и согласия не менялись.

## Фактическая проверка

- Временный отладочный хук локального WebGL-рендера проверил пять вариантов отделки: brick, tuscan, stone, plaster, gray; ракурсы: front/right/back/left. Всего 20 проходов без ошибок pageerror, для каждого в Runtime подтверждено facadeBody.material === gableFacades.material, совпадение UUID карты и наличие UV у обоих объектов.
- Снимки сохранены на подключённом ПК только во временном каталоге C:/Users/aliev/AppData/Local/Temp (kaskad-facade-...). Отладочный хук удалён перед финальной сборкой.
- Проверка нативным Node guardrail из .agents/skills/kaskad-3d-facade-qa/scripts/check-facade.mjs; затем мобильный smoke test на реальной опубликованной версии.
- Различия яркости при прямом солнце и в тени — физически корректны, но больше не означают другой материал облицовки.

## Важная граница

Уровень текстур и геометрии остаётся демонстрационным WebGL. Фотореалистичная точная модель дома потребует лицензированного детализированного GLB и PBR/LOD-пайплайна. Отдельный навык Codex: .agents/skills/kaskad-3d-model-pipeline/SKILL.md.

## Исследование инструментов и лицензий

- glTF: https://www.khronos.org/gltf/ — открытый отраслевой формат для передачи 3D, PBR, KTX2.
- glTF Transform (MIT): https://github.com/donmccurdy/glTF-Transform — подготовка GLB, Meshopt/Draco, KTX2/WebP.
- meshoptimizer/gltfpack (MIT): https://github.com/zeux/meshoptimizer — оптимизация размеров/полигонов, LOD, объединение мешей.
- NVIDIA Kaolin: https://github.com/NVIDIAGameWorks/kaolin — Python/CUDA, подходит для подготовки на RTX 3090, но не предназначен для исполнения в мобильном браузере. Часть non_commercial модулей лицензирована отдельно.
- NVIDIA instant-ngp: https://github.com/NVlabs/instant-ngp — источник NeRF-инструментария; лицензия NVIDIA Source Code License-NC запрещает коммерческое применение без отдельного разрешения. Не добавлять в коммерческий сайт.
