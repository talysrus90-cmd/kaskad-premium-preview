## 3. Граница результата и дальнейшее развитие
Полный фотореализм ТЗ НЕ достигнут: растительность, окна, заборы, фасады и бассейн по-прежнему относительно простая геометрия, PBR-покрытие не является конструктивно точным BIM-узлом. Требуются легально полученные GLB-модели/высококачественные PBR normal/roughness/LOD для деревьев и фасадов, проверка мобильного FPS и визуальных дефектов с разных ракурсов.
Автоматическая доставка клиентских заявок НЕ подключена: GitHub Pages — статический сайт, для этого нужен настроенный защищённый приём заявок и подтверждённые юридические реквизиты.
Нельзя обещать, что концептуальная приблизительная площадь = проектные размеры и смета, или выдавать изображения за построенные объекты.
