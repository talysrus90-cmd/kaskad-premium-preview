# КАСКАД v46 — интерактивный интерьер, навигация, заявка и региональная архитектура

24.11.2026. Продолжение концептуального конструктора v30.

## Интерьер / реальное вращение
- Существовавшая плоская фотография поверх WebGL отключена. Она вводила в заблуждение: двигались пальцем, но фото не поворачивалось.
- Вход в дом создаёт отдельные 3D-сцены для прихожей, гостиной, кухни, спальни и санузла только по требованию пользователя.
- Орбитальное управление ведёт себя как обзор от уровня глаз: камера остаётся около фиксированной точки, направление взгляда разворачивается на 360 градусов по горизонтали; вертикальный обзор ограничен реалистичным углом. При выборе комнаты точка обзора сбрасывается на корректную позицию.
- Пространства являются иллюстративными шоурумами. Архитектурная планировка, мебель, двери и размеры не привязаны к выбранной наружной модели и не являются проектом. Фото-реалистичность пока не достигнута. Дальнейший этап: PBR-модели и материалы, корректные проёмы, планировка и удобные точки перехода внутри связанных комнат. Не обозначать текущее состояние как полноценный цифровой двойник.

## Телефон / Android Back
- Перед входом в интерьер родительский сайт фиксирует вход в конструктор, затем создаёт отдельный шаг истории `kaskadInteriorOpen`.
- Первое системное «Назад» закрывает интерьер в iframe, восстанавливает наружную сцену и прокрутку до конструктора.
- Следующее «Назад» возвращает в исходную часть сайта, не отправляет пользователя во внешнюю страницу.

## Заявка / сохранение
- Отдельная кнопка «Весь участок» удалена с 3D-изображения. Управление участком сохранено во вкладке «Участок», доступно через этап настройки.
- Кнопка «Создать заявку» перенесена в левый верхний угол и открывает компактное меню.
- Действия: скачать текстовую конфигурацию (дата, размеры, этажность, стиль, фасад, кровля, вход, окна, ограждение, участок и благоустройство); поделиться через системное меню телефона (если API доступен; иначе скопировать); передать ту же конфигурацию в уже существующую форму обращения КАСКАД.
- Автоматическое отправление на сервер без подтверждения пользователем отсутствует. Существующий процесс отправки письма сохранён. Текст конфигурации не содержит персональные данные по умолчанию.

## Забор / вход
- Каменные пролёты теперь высотой 1,84 м со стилизованным каменным завершением; опорные столбы остаются соразмерными.
- Раздел переименован в «Вход и окна» и явно разделён на четыре варианта входа и настройки окон/двери.
- Четыре конструктивных варианта входа снабжены маленькими схемами и статусом выбора; все четыре меняют геометрию парадного входа также и в новых авторских домах.

## Архитектурные модели
- Три ранее показанных первыми Г-/П-/Т-образных одноэтажных варианта исключены из видимого каталога по отзыву пользователя.
- Добавлены самостоятельные двухэтажные объёмы: Кубанский семейный с пониженным гаражным крылом; Южная усадьба с колоннами и балконом; Кавказский коттедж с крытой боковой галереей; Современный дом со смещёнными крыльями.
- Для каждого варианта выполнены отдельные сегменты фундамента и наружных стен, два уровня проёмов, собственные скаты кровли, входные группы, балконы/пристройки по смыслу. Это авторские концепции, не копии существующих архитектурных проектов.
- Каталог состоит из 17 отобранных проектов, начинается с двухэтажных, дальше показывает мансардные и одноэтажные; вариации отделки не считаются новыми домами.
- Для четырёх новых моделей созданы отдельные карточки из наших 3D-рендеров, оптимизированные локальные WebP.
- Меняя «Стиль», пользователь не теряет отдельно выбранные фасад и цвет кровли.

## Проверки
- Playwright (локальный HTTP): 390 px, переключение всех пяти комнат, Back из интерьера, скачивание UTF-8 конфигурации, передача выбора в заявку, четыре типа входа, каталог без трёх удалённых вариантов, 17 миниатюр без недостающих файлов, каменный забор.
- Скриншоты WebGL: обзор гостиной до и после перемещения указателя (видимое изменение кадров), корректная визуализация четырёх новых двухэтажных моделей. Сохранённые QA-отчёты хранятся локально на ПК.
- GitHub Pages обновляется только после успешной проверки.

## Опыт рынка / дальнейшее развитие
Matterport и Pannellum используют переходы между реальными точками обзора, панорамы 360°, подсказки, точки интереса; полноценно это будет возможно после геометрии реальной планировки или создания качественных панорам. Современную архитектуру Краснодарского края и Кавказа нельзя свести к перекраске одной коробки. Должны различаться планы, высотность, кровельная схема, композиция крыльца и террасы.

Это визуальный эскиз для выбора направления, а не архитектурная документация или расчёт конструкций.
