## Аудит до изменений
Локальный Chromium с экраном 390×844, без сетевого замедления и без реальной Android-аппаратуры:
- Общая высота длинной мобильной страницы: ~10 508 px.
- Блок из шести этапов работ: ~2 478 px.
- Нет OpenGraph карточки для соцсетей/мессенджеров.
- Основные изображения-герой и четыре карточки галереи не имели размеров в HTML; динамическая фотография модального просмотра может оставаться без собственных width/height.
- Высота input range площади составляла 5 CSS px, что неудобно для сенсорного экрана.
- На проверенной главной не было горизонтального переполнения, битых внутренних якорей или JS pageerrors.
- 144 изображения галерей (42/42/30/30) и все их 144 миниатюры существуют в локальном дереве.

## Выполнено (ветка improvement/worldclass-mobile-20261123)
- Отдельный мобильный скролл-слайдер шести этапов на ширинах до 600 px, с кнопками «Назад»/«Вперёд» и доступным счётчиком «Этап N из 6». На планшете и компьютере прежняя сетка сохранена.
- Крупная (42 px) область касания ползунка площади калькулятора, при этом старые коэффициенты и расчёты не изменялись.
- Видимая при фокусе клавиатуры ссылка «К содержимому».
- Увеличенные интерактивные области ссылок в навигации нижнего раздела.
- Ширина и высота у главного фото и у четырёх обложек галерей, сохраняющие масштаб изображений.
- Canonical, OpenGraph, Twitter large image карточка для предпросмотра ссылки. Не добавляли фиктивные организации, адреса, рейтинги, цены, контактный адрес или JSON-LD, поскольку данные оператора пока не подтверждены.
- Обновлена версия PWA, новая CSS/JS добавлена в облегчённый офлайн-кэш.
