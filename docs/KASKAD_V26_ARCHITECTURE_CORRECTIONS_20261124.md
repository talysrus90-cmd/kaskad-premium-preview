# КАСКАД v26 — исправление архитектурных ошибок по скриншотам заказчика
Дата: 24.11.2026.
Исходная версия: v25, коммит 3706d1b.
Рабочая ветка: feature/kaskad-v26-russian-house-20261124.

## Исходные проблемы (4 скриншота с телефона)
1. Декоративные арки и элементы некоторых стилей выглядели висящими без опор.
2. Старый широкопрофильный навес над входом на отметках 4.68–4.88 м пересекался с оконными проёмами второго этажа.
3. Мансардной кровле не хватало окон, а геометрия не отражала дом «первый этаж + жилая мансарда».
4. В галерее стилей присутствовали стилистически неудачные или похожие на односкатные архитектурные варианты, не соответствовавшие пожеланиям клиента.

## Реализация
- Новая независимая группа russian-home-v26.js для четырёх компактных моделей первого этажа: семейный одноэтажный (вальмовая кровля), дом с жилой мансардой и кровельными окнами, кирпичный одноэтажный двухскатный, светлый одноэтажный. Пятый вариант — сдержанный двухэтажный коттедж на исправленной базовой модели.
- Отдельно реализованы фасад, двери, окна, цоколь, невысокое перекрытое крыльцо, несущие визуальные стойки, ступени, разные группы скатных крыш, софиты, карнизные планки. Старые колоннады и подвешенные арки больше не предлагаются в каталоге.
- Для двухэтажной старой модели заменён навес 12.2×2.6 м на центральный 3.85×1.85 м: верх около 3.17 м, окна второго этажа начинаются выше 4.7 м; стойки опираются на крыльцо. Убраны старые балконные декоративные рейки, пересекавшие оконные проёмы.
- Мансардная форма нового дома: стены первого этажа ~3.2 м, свес ~3.8 м, верх крыши ~6.7 м. Приблизительный свободный максимум ~2.6–2.8 м возле середины мансарды, переменная высота под скатами. Для точных внутренних высот нужны перекрытия, стропила, утепление, углы наклона и архитектурные расчёты. 4 настоящие объёмные рамы кровельных окон наклонены вместе со скатом, не изображают люкарны. Для двухэтажной старой мансарды тоже добавлены 4 наклонных окна.
- Крыша металлочерепицы стала более матовой: roughness↑, metalness↓, уменьшено HDR-отражение и излишний блеск от roughnessMap. Свой параметрический профиль v25 сохраняется.
- Пять новых карточек созданы из фактических изображений 3D сцены: assets/3d/cards/preset_*_v26.webp, без чужих фотографий и лицензионных проблем.
- По умолчанию выбран одноэтажный семейный вариант ~150 м², четырёхскатная крыша, серо-бежевый кирпич и графит. Бассейн опционален, начально выключен. Мобильная камера подведена ближе для лучшей видимости дома.
- Локальное сохранение конфигурации переходит на ключ kaskad-v26-visual-selection; устаревшие стили v25 не восстанавливаются. Целевой путь заявки остаётся черновиком, не подтверждённой серверной отправкой.
- CSS desktop/sidebar, мобильная панель, история Back, жесты в фотогалерее, калькулятор и PWA не должны измениться.

## Тесты браузера
- Playwright Edge: 5 отдельных 3D-компоновок, 5 отличимых изображений, JS errors=[], HTTP bad=[].
- Браузерная проверка 7 ширин 390–1920, прокрутка и все 7 стадий выбора.
- 12 комбинаций 3 скатных формы × 4 профиля металлочерепицы, unique=12.
- Финальный переход из 3D в подготовленную заявку; смена отделки, окон и ландшафта; сохранение локального выбора.
- Отдельно проверяется включение бассейна: по умолчанию теперь он выключен, поэтому прежний тест от v25 пришлось обновить по реальному продуктовому поведению.
- Регрессии Back, фотожестов, калькулятора и PWA; локальная эмуляция Android/touch не заменяет физическую проверку на Samsung.

## Не завершено
Полная фотореалистичность фасадов, растительности, бассейна и ограждений. Текущая новая модель — правдоподобная, но авторская концептуальная 3D-геометрия. Для детального архитектурного проектирования необходимо отдельно проверять конструктивные узлы, несущую способность, нормативы и точные размеры. Автоматическая серверная доставка обращений также не подключена.
